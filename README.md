<h1 align="center">UXKIN for Claude</h1>

<p align="center">
  Real UI, not AI slop: Claude looks at real app screens, user journeys and website
  design systems before it builds a screen.
</p>

This is the Claude plugin build of UXKIN. The full project, with setup for Cursor,
Codex, GitHub Copilot and other MCP clients, lives on the
[main branch](https://github.com/uxkin/agent).

## What's inside

- **no-ui-slop** skill: steers Claude away from generic AI-looking UI and toward
  layouts, copy and states that read like a real product.
- **uxkin-research** skill: tells Claude when and how to look up real references
  before designing.
- **UXKIN MCP server** (`https://uxkin.com/mcp`): search 500,000+ real iOS app
  screens, complete user journeys and 15,000+ website design systems with DESIGN.md.
  Searching needs a UXKIN account with a plan; Claude asks you to sign in the first
  time.
