Design and build a dashboard for this project. Extra context from the person: $ARGUMENTS

1. Use the `dashboard-layout` skill: write down who uses it, the questions they come to answer and the real data available (ask for what's missing, never invent metrics), look at real products if the UXKIN tools are connected, and plan the navigation, key numbers, main list or table, filters and states. Show the person the plan and wait for their go-ahead.
2. Build it with the project's components and tokens, using the `data-display` skill for every chart and table.
3. Check it rendered on desktop, tablet and phone, in light and dark mode, with the keyboard, and with empty, loading and error data.
