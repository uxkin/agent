# Landing Page Design

Plan, build and review landing pages that look like a real product, not a template: one clear visitor and action, real proof, fast and checked on desktop and phone. By [UXKIN](https://uxkin.com).

## Install

In Claude Code:

```
/plugin install landing-page-design --marketplace uxkin/agent
```

## What's inside

| | What it does |
|---|---|
| **landing-page-plan** skill | Plans the page before any code: the visitor, the one action, the sections in order, the real copy and assets each needs, and a visual direction from real websites |
| **landing-page-build** skill | Builds it on a real design system: hero, sections and call to action, real screenshots, responsive, fast, accessible, with metadata and social preview, checked rendered |
| **landing-page-review** skill | Reviews a landing page as visitors see it and lists what to fix, most important first |
| `/landing-page-design:plan` | Plan a landing page: the visitor, the action, the sections and the copy |
| `/landing-page-design:build` | Build a landing page that looks like a real product and works on every screen |
| `/landing-page-design:review` | Review a landing page and list what to fix, most important first |
| UXKIN MCP server (optional) | 15k+ design systems taken from real websites, each with a DESIGN.md |

The skills and commands work on their own, with no account. The UXKIN connection is optional: sign in with a UXKIN account when your app asks; searching the library needs a UXKIN plan.

## What it sends

The skills and commands run inside your agent and send nothing anywhere. When the UXKIN MCP server is connected, your agent sends its search words to `https://uxkin.com/mcp` and receives screens, journeys and design systems. See the [privacy policy](https://uxkin.com/privacy).
