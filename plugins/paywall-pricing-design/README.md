# Paywall & Pricing Design

Design and build paywalls, upgrade screens and pricing pages that are clear and honest: the value first, real prices and renewal terms that match checkout, one obvious choice, and every state handled, on phone and desktop. By [UXKIN](https://uxkin.com).

## Install

In Claude Code:

```
/plugin install paywall-pricing-design --marketplace uxkin/agent
```

## What's inside

| | What it does |
|---|---|
| **app-paywall** skill | Plans and builds in-app paywalls and upgrade screens: when they appear, the value, plans and trial wording, one main button, close, Restore Purchases and terms, and every purchase state |
| **pricing-page-layout** skill | Plans and builds website pricing pages: plan cards, monthly and yearly switch, comparison table, FAQ and calls to action that match checkout, on desktop and phone |
| **paywall-review** skill | Reviews an existing paywall or pricing page and lists what to fix, most important first |
| `/paywall-pricing-design:paywall` | Design and build a paywall |
| `/paywall-pricing-design:pricing` | Design and build a pricing page |
| `/paywall-pricing-design:review` | Review a paywall or pricing page |
| UXKIN MCP server (optional) | Real iOS app paywalls, trial flows and complete user journeys, and 15k+ design systems taken from real websites |

The skills and commands work on their own, with no account. The UXKIN connection is optional: sign in with a UXKIN account when your app asks; searching the library needs a UXKIN plan.

## What it sends

The skills and commands run inside your agent and send nothing anywhere. When the UXKIN MCP server is connected, your agent sends its search words to `https://uxkin.com/mcp` and receives screens, journeys and design systems. See the [privacy policy](https://uxkin.com/privacy).
