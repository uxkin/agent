# UXKIN

Search real iPhone app screens, user journeys and website design systems from [UXKIN](https://uxkin.com), and bring real UI references into Raycast AI.

## Commands

- **Search UI References:** search real app screens, complete user journeys and websites, for example "paywall", "onboarding" or "delete account". Open a journey to see every screen in order.
- **Search Design Systems:** search design systems taken from real websites, with colors and their roles, fonts and components. Copy the DESIGN.md or the colors as CSS variables.
- **My Collections:** browse the screens, apps and websites you saved on UXKIN.

## Raycast AI

Mention `@uxkin` in Raycast AI, for example "@uxkin how do meditation apps handle onboarding?" or "@uxkin find a design system for a dark fintech site". Raycast AI looks at real references before answering and links to them.

## Setup

The first time you run a command, Raycast opens uxkin.com in your browser. Log in (or create an account) and click **Allow**. There's no API key to copy.

Searching the library needs a UXKIN plan (Monthly or Lifetime). Without one, the commands tell you so and link to the plans.

## Privacy

The extension sends your search words to UXKIN and shows the results. Nothing else is sent. See the [privacy policy](https://uxkin.com/privacy).
